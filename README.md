# galerune
Tradución do Deltarune ao galego

## Indicacións
Para xogar a esta tradución necesitarás ter Deltarune comprado en [Steam](https://store.steampowered.com/app/1671210/DELTARUNE/).
Descarga e descomprime Galerune.rar e substitúe os arquivos do xogo cos novos arquivos.

## Créditos
Algúns sprites (especialmente os textos especiais do Capítulo 3) foron modificados a partir dos usados por [DeltaESP](https://deltaesp.site/) (ArceUseless, Corvex, Demi, Novu, Val, Alexis, Fran) e pola [Teiarruma](https://github.com/teiarruma/deltarune-ptbr) (refri, Dan, Uão, Mandachuva).
Agradecementos especiais a ArceUseless pola súa axuda no apartado técnico da tradución.
